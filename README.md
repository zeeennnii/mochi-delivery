# 🍡 Mochi Delivery

Mochi Delivery is a simple 2D browser game made with HTML, CSS, and JavaScript. Catch falling mochi, avoid water puddles, and try to get the highest score before time runs out.

## How to Play
- Catch each mochi to earn **10 points**.
- Avoid water puddles. Each puddle removes **1 life**.
- Start with **3 lives** and **45 seconds**.
- The game ends when all lives are lost or the timer reaches zero.
- Items fall faster and spawn more often as your score increases.

## Controls
- **Computer:** Left/Right arrow keys or A/D.
- **Mobile:** Press and hold the on-screen arrow buttons.
- Use **Start Game** to begin and **Restart** to play again.

## Project Files
- `index.html` – page structure and game interface.
- `css/style.css` – page layout, colors, and button styling.
- `js/script.js` – game logic, movement, collisions, score, lives, and timer.

## Run Locally
Download or clone this repository and open `index.html` in a modern web browser. No installation or build tools are required.

## Hosting with GitHub Pages
In the repository, open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, choose the `main` branch and `/ (root)` folder, then save.
